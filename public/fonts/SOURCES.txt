Font files, their upstream sources, instances, unicode ranges and measured byte sizes.
Spec: docs/superpowers/specs/2026-11-12-darkroom.md §4.1-4.2. Build: bun run fonts (scripts/fonts/build.sh).
Every face is OFL 1.1 with no Reserved Font Name; the licence for each is OFL-<Family>.txt here.

Ranges

          U+2000-206F,U+20AC,U+2122,U+2191,U+2193,U+2212,U+2215,U+FEFF,U+FFFD
  EXTA    U+0100-017F (Latin Extended-A, for the IAST macron letters)
  ARROWS  U+2190-2199 (Archivo's cmap carries them, so no Chivo Mono fallback is needed on the site)
  IAST-GREEK  U+0323,U+0391-03A9,U+03B1-03C9 and the IAST dot-below letters

The "static subsets" rule is relaxed for Archivo only (Darkroom, 2026-11-12): the width axis is
the site's voice switch (labels at wdth 62, display at 125), and one variable file is smaller than
the five static instances it replaces. Latin Extended-A would take that file to about 115 KB, over
the 95 KB budget, so it ships as a second variable file that loads only when a page uses one of
its letters (unicode-range).
